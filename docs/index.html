Personal Publishing Framework

Let the source endure.

PPF is a source-centered, portable framework for developing, sharing, and publishing knowledge and creative work.

让源材料持续存在

PPF 将创作者拥有的源材料，与 HTML、EPUB、PDF、DOCX、LaTeX 等出版格式及其交付平台分离。格式和平台可以更换，源材料应当能够持续、可重建。

The publication lifecycle

  1. Source — durable, creator-controlled material
  2. Build — transform source into formats
  3. Publish — make an output accessible
  4. Release — freeze an intentional edition
  5. Archive — preserve reconstructable state
